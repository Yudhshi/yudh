# 黒暗森林と競馬場 — スライド骨子

# 目的・相手・制約（必須）

| 項目 | 値 |
|---|---|
| 目的 | 新卒の読書発表として、『三体』の面白さと「テンセントは競争をやめず、戦う場所を顧客の前から社内へ移した」を持ち帰ってもらう。提案はしない |
| 届ける相手 | 営業出身の社長（主）、デザイナーの同僚と新卒。『三体』は未読の人が多く、中国での位置づけも知らない。中国ITの固有名詞にはなじみがない |
| 形式 | 対面・社内勉強会（シャチョケン戦略編）・時間は制限なし（まず完成度を優先） |
| スタイル | 未定。当面は goodpatch 準拠のプリセットで作る |

## 入れたい論点

1. 日本で『キングダム』から戦略やリーダーシップを学ぶように、中国では『三体』から競争のルールと生き残り方を学ぶ
2. 黒暗森林：見つけたら撃つ。だから、みんな隠れている（宇宙人の問いから入る）
3. でも黒暗森林の前提は商売に当てはまらない。同じ『三体Ⅱ』の面壁計画が、「重複」というヒントをくれる
4. 2010年11月、テンセントは外でのケンカをやめ、社内でWeChatを育てた
5. 競馬の限界と、なぜ今この話か（AIで技術爆発が毎月起き、重複は安くなった）

## ゴール（参加者の終了時状態）

1. 『三体』が中国でどんな本として読まれているかを知っている
2. 「戦う場所を、顧客の前から社内へ移した」を自分の言葉で言い直せる
3. 『三体』を読んでみたくなっている
