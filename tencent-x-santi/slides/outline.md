# 黒暗森林と競馬場 — スライド骨子

# 目的・相手・制約（必須）

| 項目 | 値 |
|---|---|
| 目的 | 新卒の読書発表として、『三体』の面白さと「テンセントは競争をやめず、戦う場所を顧客の前から社内へ移した」を持ち帰ってもらう。提案はしない |
| 届ける相手 | 営業出身の社長（主。新しくて面白いものが好き）、デザイナーの同僚と新卒。『三体』は未読の人が多く、中国ITの固有名詞にはなじみがない |
| 形式 | 対面・社内勉強会（シャチョケン戦略編）・時間は制限なし |
| スタイル | 未定。当面は goodpatch 準拠のプリセット。1枚1メッセージ、文字は重点だけ（Apple の発表スライドを参考） |

## 入れたい論点

1. 日本で『キングダム』から戦略やリーダーシップを学ぶように、中国では『三体』から競争のルールと生き残り方を学ぶ
2. 黒暗森林：見つけたら撃つ。だから、みんな隠れている（宇宙人の問いから入る）
3. その「森のルール」は会社でそのままは使えない。でも同じ『三体Ⅱ』の面壁計画が「重複」というヒントをくれる
4. 2010年11月、テンセントは外でのケンカをやめ、社内でWeChatを育てた
5. 戦う場所を、顧客の前から社内へ。そして今、AIで重複は安くなった

## ゴール（参加者の終了時状態）

1. 『三体』が中国でどんな本として読まれているかを知っている
2. 「戦う場所を、顧客の前から社内へ移した」を自分の言葉で言い直せる
3. 『三体』を読んでみたくなっている
