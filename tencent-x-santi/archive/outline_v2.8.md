# 黒暗森林と競馬場 — スライド骨子

# 目的・相手・制約（必須）

| 項目 | 値 |
|---|---|
| 目的 | 社長に『三体』を「読みたい1冊」として選んでもらう。持ち帰る一言は「外で撃たず、中で競う。」 |
| 届ける相手 | 営業出身の社長（主。新しくて面白いものが好き。発表のあと1冊を選んで注文する）、デザイナーの同僚と新卒 |
| 形式 | 対面・社内勉強会（シャチョケン戦略編）・時間は制限なし |
| スタイル | 未定。当面は goodpatch 準拠。画面はキーワードだけ、ページ番号と脚注なし。Part 4 はテンセントの企業カラー |

## 入れたい論点

1. 日本のキングダム ≒ 中国の三体（競争と生き残りを学ぶ本）
2. 黒暗森林：見つけたら撃つ。だから隠れる
3. 森のルールはそのままでは使えない。でも面壁計画が「重複は保険」というメガネをくれる
4. 2010年11月、テンセントは外で撃たず、中で競わせた（WeChat）
5. 『三体』は社長への1冊。面壁者4人、勝つのは誰か

## ゴール（参加者の終了時状態）

1. 社長が『三体』を読みたくなっている
2. 「外で撃たず、中で競う。」を覚えている
3. 26卒が中国版ドラマを見てみようと思っている
