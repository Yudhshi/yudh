# 黒暗森林と競馬場 — スライド骨子

# 目的・相手・制約（必須）

| 項目 | 値 |
|---|---|
| 目的 | 「テンセントは競争をやめず、戦う場所を顧客の前から社内へ移した」を持ち帰ってもらい、今期1案件で「社内競馬」を試す承認をもらう |
| 届ける相手 | 営業出身の社長（主）、デザイナーの同僚と新卒。『三体』は未読の人が多く、中国での位置づけも知らない。中国ITの固有名詞にはなじみがない |
| 形式 | 対面・社内勉強会（シャチョケン戦略編）・時間は制限なし（まず完成度を優先） |
| スタイル | 未定。当面は goodpatch 準拠のプリセットで作る |

## 入れたい論点

1. 『三体』は中国ビジネス界の『キングダム』。競争のルールと生き残り方を学ぶ本として読まれている
2. 『三体』の黒暗森林は「一回きり」が前提で、何度も続く商売には当てはまらない
3. 2010年11月、テンセントは外での撃ち合いをやめ、社内で自社製品同士を競わせた（WeChat）
4. 営業では御法度の「同じ客を二人で追う」を、開発ではあえてやった。決めるのは審査員ではなくユーザー
5. 競馬の限界：同じ血統の馬を何頭走らせても、競技が変われば勝てない
6. いまはAIで技術爆発が毎月起き、重複は安くなった。だから今期、1案件で「社内競馬」を試したい

## ゴール（参加者の終了時状態）

1. 「戦う場所を、顧客の前から社内へ移した」を自分の言葉で言い直せる
2. 「重複はムダ」の反対側にある「重複は技術爆発への保険」という見方を知っている
3. 社長が、1案件・約20人日の社内競馬にその場でイエスかノーを言える

## 各Partの主要メッセージとブレイクダウン

### Part 1: 今日話したいこと
**主要メッセージ**: 『三体』は中国ビジネス界の『キングダム』。それを読んだら、テンセントの2010年11月にたどり着いた

**ブレイクダウン**:
- 表紙：黒暗森林と競馬場／2010年11月、テンセントが選んだ戦略
- はじめに：『キングダム』で戦略・リーダーシップを学ぶ日本、『三体』で競争のルールと生き残り方を学ぶ中国
- 結論から：テンセントは競争をやめなかった。戦う場所を、顧客の前から社内へ移した

### Part 2: 紹介する本
**主要メッセージ**: 中国で育った自分だから紹介できる本。キーワードは「黒暗森林」

**ブレイクダウン**:
- 『三体』：三部作で100万部、Netflix。中国版ドラマはテンセント系の制作 [IMG: 講演者が自分で撮った『三体』実物の写真。AI生成画像は使わない]
- 私と三体：中国にいた頃と、日本に来てから（講演者の実体験）
- なぜこの本か：戦略は専門外のUI/UXデザイナー → 中国で育った自分にしか話せない本にしよう
- 黒暗森林を一言で：「見つかったら撃たれる。だから先に撃つ。」キーワード「猜疑連鎖」「技術爆発」

### Part 3: 本を読んで
**主要メッセージ**: 『三体』を読んでも戦略はわからない。でも「重複」という新しいメガネが手に入る

**ブレイクダウン**:
- 感想：「正直、『三体』を読んでも戦略はわからない。」
- 前提のズレ：黒暗森林「一回きり／隠れれば生き残る」、商売「何度も続く／評判は全部見られる」
- 聞いてみた：対話の吹き出しで、相手の一言（講演者が記入）
- 新しいメガネ：「ムダに見える重複が、「技術爆発」への保険になる。」

### Part 4: 2010年11月に戻る
**主要メッセージ**: 森の撃ち合いをやめ、社内に競馬場をつくった。同じ1か月の中で

**ブレイクダウン**:
- 章扉：26卒の多くは小学1年生。Goodpatch創業の10か月前
- 全景：5つの日付のカレンダー
- 11/3・11/4：QQが「QQか360か」を迫る。9月から続いた猜疑の連鎖
- 11/11：最強より、最も尊敬される会社へ
- 11/20：外で叱られた頃、中でWeChatが始まった
- 11/21：一流の営業ほど「うちか他社か」を迫らない
- 全部点灯：赤は森での撃ち合い、青はテンセントの答え
- 引用：馬化騰（2013）
- そして今：そのWeChatは、いまや生活インフラ（講演者のWeChat） [IMG: 講演者のWeChat画面のスクリーンショット。個人情報はぼかす]
- 営業では御法度の「同じ客を二人で追う」を、開発ではあえてやった
- 日本との比較：審査員が1案に絞る vs 競わせて、ユーザーが選ぶ
- その後：オープン化は道半ば
- 競馬の限界：抖音はテンセントにとっての技術爆発だった

### Part 5: まとめ
**主要メッセージ**: いまはAIで重複が安くなった。今期、1案件で「社内競馬」を試させてください

**ブレイクダウン**:
- 2冊を、誰にどう薦めるか：26卒へ／忙しい社長へ [IMG: 講演者が自分で撮った2冊の実物の写真]
- なぜ今：いまは、AIで毎月のように技術爆発が起きる。そして重複は、AIで安くなった
- 提案：対象・規模・前提・判定・お願いの5行と、営業にとってのメリット
