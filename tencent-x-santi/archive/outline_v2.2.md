# 黒暗森林と競馬場 — スライド骨子

# 目的・相手・制約（必須）

| 項目 | 値 |
|---|---|
| 目的 | 「テンセントは競争をやめず、戦う場所を顧客の前から社内へ移した」を持ち帰ってもらい、今期1案件で「社内競馬」を試す承認をもらう |
| 届ける相手 | 営業出身の社長（主）、デザイナーの同僚と新卒。『三体』は未読の人が多く、中国ITの固有名詞にはなじみがない |
| 形式 | 対面・社内勉強会（シャチョケン戦略編）・20分想定（要確認） |
| スタイル | おまかせ（goodpatch 準拠） |

## 入れたい論点

1. 『三体』の黒暗森林は「一回きり」が前提で、何度も続く商売には当てはまらない
2. 2010年11月、テンセントは外での撃ち合いをやめ、社内で自社製品同士を競わせた（WeChat）
3. 日本の社内競争は審査員が決めることが多い。テンセントはユーザーに決めさせた
4. 競馬の限界：同じ血統の馬を何頭走らせても、競技が変われば勝てない
5. 今期、1案件で「社内競馬」を試させてほしい

## ゴール（参加者の終了時状態）

1. 「戦う場所を、顧客の前から社内へ移した」を自分の言葉で言い直せる
2. 「重複はムダ」の反対側にある「重複は技術爆発への保険」という見方を知っている
3. 社長が、1案件・約20人日の社内競馬にその場でイエスかノーを言える

## 各Partの主要メッセージとブレイクダウン

### Part 1: 今日話したいこと
**主要メッセージ**: テンセントは競争をやめなかった。戦う場所を、顧客の前から社内へ移した

**ブレイクダウン**:
- 表紙：黒暗森林と競馬場／2010年11月、テンセントが選んだ戦略
- 結論から：大字で主張。小字「QQの会社が、QQを食う製品を自分で作った。入口は『三体』、舞台は2010年11月。」

### Part 2: 紹介する本
**主要メッセージ**: 中国には『三体』で競争を語るIT経営者がいる。キーワードは「黒暗森林」

**ブレイクダウン**:
- 『三体』：日本で100万部、Netflix。角落に「中国版ドラマ（2023）はテンセント系の制作。Netflix版とは別作品」。ページ下に「第2部の考え方に触れます。第3部の展開には触れません」 [IMG: 講演者が自分で撮った『三体』実物の写真。AI生成画像は使わない]
- 私と三体：中国にいた頃と、日本に来てからの実体験（講演者が記入）
- なぜこの本か：「日本の経営者が『キングダム』で組織を語るように、中国には『三体』で競争を語るIT経営者がいる。」小字で雷軍（2018）の一言
- 黒暗森林を一言で：「見つかったら撃たれる。だから先に撃つ。」小字「猜疑連鎖・技術爆発（あとで2回ずつ出てきます）」

### Part 3: 本を読んで
**主要メッセージ**: 『三体』を読んでも戦略はわからない。でも「重複」という新しいメガネが手に入る

**ブレイクダウン**:
- 感想：「正直、『三体』を読んでも戦略はわからない。」小字「経営者の"三体語録"も、原作とは違う言葉が多かった。」
- 前提のズレ：黒暗森林「一回きり／隠れれば生き残る」、商売「何度も続く／評判は全部見られる」。営業句「これは、営業が一番よく知っている。」
- 聞いてみた：「中国の経営者は『三体』に何を見ていたと思う？」への相手の一言（講演者が記入。見つからなければ『三体Ⅱ』の面壁計画で代替）
- 新しいメガネ：「重複は「ムダ」ではなく、「技術爆発」への保険。」小字で馬化騰（2012）の冗長性の言葉と「賽馬（競馬）」の説明

### Part 4: 2010年11月に戻る
**主要メッセージ**: 森の撃ち合いをやめ、社内に競馬場をつくった。同じ1か月の中で

**ブレイクダウン**:
- 全景：5つの日付のカレンダー（11/3・11/4・11/11・11/20・11/21）。QQ・360の注記と『テンセント』の出典
- 11/3・11/4：QQが「QQか360か」を迫る。三体の言葉で言えば猜疑の連鎖
- 11/11：最も尊敬される会社へ。猜疑の連鎖を自分から断ちにいった
- 11/20：外で叱られた頃、中でWeChatが始まった。日付が近いのは偶然
- 11/21：両社が謝罪。営業句「一流の営業ほど、「うちか他社か」を迫らない。」
- 全部点亮：赤＝森での撃ち合い、青＝テンセントの答え
- 引用：馬化騰（2013）「もしWeChatが他社から出ていたら、我々はおそらく止められなかった。」
- 日本との比較：審査員が1案に絞る vs 競わせて、ユーザーが選ぶ
- その後：オープン化は道半ば。2021年9月の行政指導まで壁が残った
- 競馬の限界：抖音はテンセントにとっての技術爆発だった

### Part 5: まとめ
**主要メッセージ**: 今期、1案件で「社内競馬」を試させてください

**ブレイクダウン**:
- 本の評価と読み方：『三体』は競争の言葉をくれる／『テンセント』は第13〜15章で足りる／読む順番 [IMG: 講演者が自分で撮った2冊の実物の写真]
- 提案：規模・前提・判定・お願いの4行と、営業にとってのメリット
