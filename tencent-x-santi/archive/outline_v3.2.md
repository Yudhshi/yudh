# 黒暗森林と競馬場 — スライド骨子

# 目的・相手・制約（必須）

| 項目 | 値 |
|---|---|
| 目的 | 社長が自然に『三体』を読みたくなる。持ち帰る一言は「外で撃つより中で競う」 |
| 届ける相手 | 営業出身の社長（主。新しくて面白いものが好き。発表のあと1冊を選んで注文する）、デザイナーの同僚と新卒 |
| 形式 | 対面・社内勉強会（シャチョケン戦略編）・時間は制限なし |
| スタイル | 未定。当面は goodpatch 準拠。キーワードと短い文だけ。句読点も全角スペースも使わず、1文1行。ページ番号と脚注なし。Part 4 はテンセントの企業カラー |

## 入れたい論点

1. 三体は中国のキングダム（競争と生き残りを学ぶ本）
2. 黒暗森林：見つけたら撃つ　だからみんな隠れる
3. 森のルールはそのままでは使えない。でも面壁計画が「重複は保険になる」というメガネをくれる
4. テンセントはトヨタとソニーを足しても届かない大きさ。2010年11月　外の撃ち合いと同じ月に、社内では3チームが同じものを作っていた（WeChat）
5. 『三体』のおすすめポイントと、最後の問い「人類は勝てるのか」（答えは本の中）

## ゴール（参加者の終了時状態）

1. 社長が『三体』を読んでみたくなっている
2. 「外で撃つより中で競う」を覚えている
3. 26卒が中国版ドラマを見てみようと思っている
